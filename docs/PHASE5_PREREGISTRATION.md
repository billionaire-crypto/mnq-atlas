1. Scope and boundary
Phase 5 implements only the market-free whole-group stationary bootstrap machinery of frozen spec §7.3 and §15 row 5, gated by §13 test 8. It implements no conditioners, volatility states, excursions, contrasts, positivity, prevalence, nulls, surfaces, reports, S01A, confirmation, or forward-vintage consumption. core/ sees numeric arrays, ordered opaque contiguous group labels, weights, probabilities, and an explicit Generator; it never sees MNQ, calendars, phases, horizons, holidays, the locked tier, or profitability, and it imports no constants, YAML, ledger, spine, outcomes, conditioners, studies, reports, or nulls.

2. Ordered groups and the stationary transition
Input group labels are a non-empty, one-dimensional, row-aligned vector in chronological group order. Every label occupies one contiguous row region; a label reappearing after another label fails closed. Inputs are never mutated.
Let S be the number of ordered unique groups. A plan contains exactly S selected whole-group occurrences, duplicates included.
Mean block length L is a finite, non-bool real scalar with L ≥ 1; restart probability is exactly p = 1/L.
Exact RNG consumption. The first and only RNG consumption before the occurrence loop is exactly one rng.integers(S) (NumPy half-open range [0, S)), selecting the initial group position. The S−1 transition decisions then occur in selected-occurrence order. At each transition, consume exactly one rng.random(); if that value is less than p, consume exactly one rng.integers(S) and restart at that position; otherwise advance to the next chronological group with circular wrap from S−1 to 0. At L=1 the transition uniform is still consumed, followed by the restart-position integer. Consume no transition RNG after selected occurrence S. No other RNG consumption occurs.
"Truncate the final block" means stop after selected occurrence S; never construct a row target and never slice a group by rows.
3. Immutable plan
The plan records ordered_group_labels, group_count, mean_block_groups, restart_probability, selected_positions, multiplicities, block_start_flags, and restart_count, with sequence fields as immutable tuples. block_start_flags[0] is true; subsequent flags record actual restart decisions, including a restart that lands where continuation would have led. multiplicities aligns to ordered_group_labels, contains nonnegative integers, sums exactly to S, and exactly matches selected_positions. Plan application verifies the supplied row-aligned group vector carries the exact ordered labels recorded in the plan before mapping group multiplicities to rows.

4. Joint coherence
One plan serves the entire aligned frame. All outcome arrays and eligibility masks in a replication receive the same plan; masks are applied only after the global plan; no production API redraws per outcome, statistic, horizon, array, or mask, and no pre-filtering to groups containing a requested cell occurs before resampling. The public boundary prefers stationary_group_resample(...), apply_group_multiplicities(...), and percentile_interval(...) over premature orchestration.

5. Weight composition
Phase 4 baseline weights are constructed once. Each draw multiplies every unchanged row baseline weight by its group's integer multiplicity. No pre-normalization, no production row expansion, no weight reconstruction over distinct selected groups, no second quantile implementation. All point statistics, bootstrap statistics, and interval endpoints use the existing Phase 4 weighted_quantile(s) path. Equal-replicate interval weights are literal float64 ones, not 1/B. An all-ones multiplicity vector produces an array byte-identical to the baseline weights and reproduces the Phase 4 point estimate exactly, proven for both session-equal primary and anchor-equal companion baselines.

10. AR(1) discriminator
24 independent paired datasets: 64 sessions × 32 rows; within each session x[0] = z[0], x[t] = 0.8·x[t−1] + 0.6·z[t] with iid standard Normal innovations (unit stationary marginal variance from t = 0, verified analytically); sessions reset independently. Compare, on the same dataset, the production whole-session stationary bootstrap (L = 5, 999 draws) against a test-only i.i.d. row-bootstrap oracle drawing exactly 2,048 row positions with replacement, converted to integer row multiplicities, composed with the same baseline weights and identical statistic/interval paths; the oracle is never exported from tests. Seed schedule: SeedSequence(ar_root_entropy).spawn(24), each outer spawning (data, session, row). Non-finite or nonpositive widths fail closed. Aggregate: median_ratio = weighted_quantile(ratios, ones(24), 0.5) (the 12th ordered ratio, verified by execution). Pass only if median_ratio ≥ 1.50 and at least 20 of 24 session widths exceed row widths. Thresholds were fixed before execution; the ≈2.36 sign-indicator design value (independently recomputed: 2.3614) is a heuristic, not an acceptance parameter.

11. One-shot acceptance failure protocol
Fixtures run only after the ratified preregistration commit, one execution each under the recorded seed schedule. On any failure: stop immediately; before any other action record the preregistration commit, implementation commit, environment fingerprint, complete command, exact test output, exception details, coverage count (if applicable), and all paired AR widths and ratios (if applicable). No rerun, no reseed, no bound adjustment, no change to fixture, DGP, draw count, block length, seed schedule, AR coefficient, aggregation rule, or materiality threshold, and no preregistration edit. Diagnosis of deterministic defects proceeds without another stochastic acceptance run. A later rerun requires a new explicit user ruling and independent audit; the original failure remains permanently recorded. Declared one-shot false-failure properties: coverage ideal-null 1 − 0.9671879248 = 0.0328120752 (computed); correct-implementation coverage-gate risk approximately 3–8% (inferred, unmeasured, since true finite-sample coverage need not equal 0.95 exactly); AR gate nonzero (unmeasured). These declarations are not permission to retry a failed seed.

12. Undefined or zero-mass replicates
Any requested replicate statistic with zero positive mass, invalid or non-finite values or weights, a non-finite statistic, a missing draw, or a plan/group/weight mismatch raises SpineError with the replicate index; no interval is constructed. No NaN returns, no finite-filtering, no denominator reduction, no retry, no redraw. Phase 5 does not invent the Phase 8 status taxonomy; a future result layer may catch and emit an explicit status.
